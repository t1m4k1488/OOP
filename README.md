# Лабораторная работа №3

Разработка API для выполнения CRUD-операций с таблицами в реляционной базе данных.

## Тематика базы данных
Тема базы данных: книжный каталог.

База данных хранит информацию об авторах, книгах и жанрах.  
Для работы используется ASP.NET Core Web API, Entity Framework Core и SQLite.

SQLite — это настоящая реляционная база данных. В этом проекте база создается в файле `book_catalog.db` при первом запуске приложения.

## Таблицы
В базе данных есть 4 таблицы:

1. `Authors` — авторы.
2. `Books` — книги.
3. `Genres` — жанры.
4. `BookGenres` — промежуточная таблица для связи книг и жанров.

По заданию требовалось минимум 3 таблицы. Здесь таблиц 4, потому что для нормальной реализации связи «многие ко многим» нужна промежуточная таблица.

## Связи между таблицами

### Связь «один ко многим»
Один автор может написать много книг.

То есть:

`Authors 1 — * Books`

В таблице `Books` есть внешний ключ:

```sql
AuthorId INTEGER NOT NULL
```

Он указывает, какому автору принадлежит книга.

### Связь «многие ко многим»
Одна книга может иметь несколько жанров.  
Один жанр может относиться к нескольким книгам.

То есть:

`Books * — * Genres`

Эта связь реализована через промежуточную таблицу:

`BookGenres`

В ней хранятся пары:

```sql
BookId
GenreId
```

## Как запустить проект

1. Установить .NET 8 SDK.
2. Открыть папку проекта в Visual Studio или VS Code.
3. Выполнить команды:

```bash
dotnet restore
dotnet run
```

После первого запуска рядом с проектом появится файл базы данных:

```text
book_catalog.db
```

4. Открыть Swagger в браузере:

```text
https://localhost:номер_порта/swagger
```

Или:

```text
http://localhost:номер_порта/swagger
```


## Новый веб-интерфейс

В проект добавлена обычная веб-страница для удобной работы с базой данных.
После запуска проекта нужно открыть в браузере:

```text
http://localhost:5000
```

На странице можно:

1. переключать язык интерфейса: русский / английский;
2. смотреть количество записей в таблицах;
3. просматривать таблицы `Authors`, `Books`, `Genres`, `BookGenres`;
4. добавлять, изменять и удалять авторов;
5. добавлять, изменять и удалять жанры;
6. добавлять, изменять и удалять книги;
7. отдельно добавлять и удалять связи между книгами и жанрами в таблице `BookGenres`;
8. перейти в Swagger по кнопке «Открыть Swagger».


## Как пользоваться интерфейсом

1. Запустить проект:

```bash
dotnet run
```

2. Открыть:

```text
http://localhost:5000
```

3. На вкладке «Авторы» можно добавить или изменить автора.
4. На вкладке «Жанры» можно добавить или изменить жанр.
5. На вкладке «Книги» можно добавить книгу, выбрать автора и отметить несколько жанров.
6. На вкладке «Связи книга-жанр» можно отдельно управлять связью многие-ко-многим.
7. На вкладке «Все таблицы» можно увидеть содержимое всех таблиц базы данных.

## Основные CRUD-методы

### Авторы

```text
GET    /api/authors
GET    /api/authors/{id}
POST   /api/authors
PUT    /api/authors/{id}
DELETE /api/authors/{id}
```

### Книги

```text
GET    /api/books
GET    /api/books/{id}
POST   /api/books
PUT    /api/books/{id}
DELETE /api/books/{id}
```

### Жанры

```text
GET    /api/genres
GET    /api/genres/{id}
POST   /api/genres
PUT    /api/genres/{id}
DELETE /api/genres/{id}
```

### Дополнительные методы для связи многие ко многим

Добавить книге жанр:

```text
POST /api/books/{bookId}/genres/{genreId}
```

Удалить жанр у книги:

```text
DELETE /api/books/{bookId}/genres/{genreId}
```
